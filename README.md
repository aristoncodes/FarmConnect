# FarmConnect

A compact React Native shopping app (Expo) UI example — product listing, cart, auth flows and simple checkout UI.

## Quick start

Prerequisites: Node.js (LTS) and npm or yarn. Optionally install the Expo CLI for extra convenience.

1. Clone the repo and enter the folder


   ```bash
   git clone <repo-url> && cd Farm-Connect-COPY

2. Install dependencies

   ```bash
   npm install

3. Start the dev server (Expo)

   ```bash
   npm start

4. Run on device/emulator

   - Android: npm run android
   - iOS: npm run ios
   - Web: npm run web

When the Expo dev tools open you can scan the QR code with Expo Go or open an emulator.

## Helpful scripts
```bash

- npm run start — start Expo dev server
- npm run android / ios / web — platform-specific launch
- npm run lint — run ESLint
- npm run format — run Prettier
```
